# Castellum Docs

Castellum is a privacy-compliant subject database for scientific
research.

## Status

The Castellum project is still in development. Therefore, there may occur some 
outdated and/or obscure statements in the related docs. Yet, we are eager to keep
docs and code in sync. Please [submit](https://git.mpib-berlin.mpg.de/castellum/documentation/issues) an issue if you encounter serious problems.
